kindle越狱插件-自定义屏保插件
ScreenSavers Hack插件功能太多，个人只是需要替换了系统的屏保图片而已
此插件脚本取自于https://zhuanlan.zhihu.com/p/24951009229，公众号:mobibooks小书馆
用AI折腾了一下，写了个插件方便自己使用
脚本核心就是软链接/usr/share/blanket/screensaver到kindle目录,没有什么技术含量

使用方法：
kindle根目录，创建文件夹screensaver（脚本也会自动创建），放入适合自己机器分辨率的图片
图片命名规则必须为bg_ssxx.png，（bg_ss00.png，bg_ss01.png，bg_ss02.png....）
启用插件后未生效，重启
